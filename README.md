# Sistema de Operações com Matrizes em C

## Descrição

Este projeto consiste no desenvolvimento de um sistema
computacional em linguagem C para realizar operações
matemáticas com duas ou mais matrizes.

O programa permite cadastrar matrizes, informar suas
dimensões e seus elementos individualmente e executar
operações matemáticas por meio de um menu interativo.

## Funcionalidades

- Cadastro de duas ou mais matrizes.
- Definição da quantidade de linhas e colunas.
- Leitura individual dos elementos.
- Exibição das matrizes cadastradas.
- Adição de matrizes.
- Subtração de matrizes.
- Multiplicação de matrizes.
- Divisão matricial utilizando matriz inversa.
- Verificação de dimensões incompatíveis.
- Identificação de matrizes singulares.
- Menu para realizar novas operações ou encerrar o programa.

## Tecnologias utilizadas

- Linguagem C.
- Biblioteca stdio.h.
- Compilador GCC.

## Como executar

1. Clone o repositório:

   git clone URL_DO_REPOSITORIO

2. Acesse a pasta do projeto.

3. Compile o programa:

   gcc main.c -o matrizes

4. Execute:

   ./matrizes

No Windows, execute:

   matrizes.exe

## Limitações

O programa trabalha com matrizes de até 10 linhas e
10 colunas, permitindo cadastrar até 10 matrizes.
